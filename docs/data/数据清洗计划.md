# CineScope 数据获取、清洗、融合与提交整理计划

## 1. 数据集选择

一期选择 GroupLens 官方 `ml-latest-small` 数据集。

选择理由：

- 数据量适合课程项目和本地开发。
- 包含电影、评分、标签和外部 ID 映射。
- `links.csv` 中包含 `tmdbId`，可与 TMDb 详情数据对齐。

MovieLens 官方入口：https://grouplens.org/datasets/movielens/

## 2. 数据源

### MovieLens

- `movies.csv`：`movieId`、`title`、`genres`
- `ratings.csv`：`userId`、`movieId`、`rating`、`timestamp`
- `tags.csv`：`userId`、`movieId`、`tag`、`timestamp`
- `links.csv`：`movieId`、`imdbId`、`tmdbId`

### TMDb

TMDb 用于补充简介、片长、热度、原始语言、海报和背景图。

匹配策略：

1. 优先使用 MovieLens `tmdbId` 请求 TMDb movie 详情。
2. movie 端点失败时尝试 TV 端点。
3. movie 和 TV 均失败时，使用 `imdb_tt_id` 通过 TMDb external ID 兜底。
4. 优先请求 `zh-CN`，并使用 `en-US` 兜底补齐缺失字段。

## 3. 清洗与融合流程

1. 下载并解压 MovieLens `ml-latest-small`。
2. 统一字段命名为 snake_case。
3. 从 MovieLens 标题中解析 `title_clean` 和 `movie_year`。
4. 将 `genres` 转换为 `genres_json`。
5. 将评分时间和标签时间转换为 UTC ISO 字符串。
6. 标签去除首尾空白并生成小写归一化字段 `tag_norm`。
7. 聚合电影评分统计：评分数、均分、中位数等。
8. 聚合高频标签，生成 `top_tags_json`。
9. 融合 TMDb 详情字段。
10. 剔除缺失 `tmdb_id` 或无法获取 TMDb 详情的电影。
11. 同步剔除不在终版电影集合中的评分和标签。
12. 按 `localDocs/RQ.md` 裁剪提交字段。

## 4. 提交整理规则

### `movies.csv`

只保留：

- `movie_id`
- `title_clean`
- `movie_year`
- `genres_json`
- `imdb_id`
- `tmdb_id`
- `imdb_tt_id`
- `rating_count`
- `rating_mean`
- `rating_median`
- `tag_count`
- `top_tags_json`
- `overview`
- `runtime_minutes`
- `tmdb_popularity`
- `original_language`
- `poster_url`
- `backdrop_url`

### `ratings.csv`

字段全部保留。

### `tags.csv`

删除原始 `tag` 字段，保留其他字段。

### `genre_stats.csv`

字段全部保留。

### `movie_features.csv`

不作为终版提交文件。

## 5. ETL 执行方式

完整流程：

```powershell
python ETL/prepare_movie_data.py
```

只基于现有 `data/final/` 重新整理提交字段：

```powershell
python -B ETL/prepare_movie_data.py --submission-only
```

`-B` 用于禁止生成 Python 字节码缓存，不影响数据处理逻辑。
