# CineScope：一个智能电影推荐Agent

## 一、选题背景

本项目计划完成一个从数据处理、推荐建模到交互展示的电影推荐系统。相比只做电影评分统计或单一模型预测，本项目更关注一个真实应用场景：用户如何用自然语言表达观影需求，并获得有依据、可解释的电影推荐。

MovieLens 数据集中包含用户评分、电影类型和用户标签，适合用于分析用户偏好和训练推荐模型。但在真实使用中，用户往往不会只输入一个用户 ID，而是会提出更自然的需求。因此，本项目计划在传统推荐算法的基础上接入外部大语言模型 API，构建一个能够理解自然语言需求的电影推荐 Agent。

系统中的大模型不直接生成电影信息，而是负责理解用户问题、调用本地推荐模块，并结合检索到的项目分析结果生成回答。推荐结果仍然来自 MovieLens、IMDb 等真实数据和本地算法计算结果。

项目最终希望实现一个前后端分离的 Web 应用。前端负责数据分析结果、用户偏好画像、推荐列表和对话入口的展示；后端负责向前端提供接口、调用推荐算法、接入外部大模型 API。

## 二、数据来源

本项目以 MovieLens 数据集作为核心数据源，并融合 IMDb 电影元数据，以增强电影内容信息和外部评分信息。

MovieLens 数据主要提供用户行为数据，包括用户评分、电影标题、电影类型、用户标签以及与 IMDb 的 ID 映射关系。它将作为推荐模型训练和用户偏好分析的基础。通过评分数据，可以分析用户对不同电影的偏好；通过电影类型和标签信息，可以构建电影内容特征；通过用户历史评分，可以实现个性化推荐。

IMDb 数据主要用于补充电影的外部信息，例如上映年份、片长、IMDb 平均评分和投票人数。这些信息可以帮助系统更全面地描述电影，也可以用于后续分析电影热度、口碑和内容特征。

经过处理后，项目将形成一个融合后的本地电影数据集，包括用户评分、电影类型、用户标签、IMDb 外部评分、上映年份、片长和投票人数等信息。
