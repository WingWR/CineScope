终版数据位于 `data/final/`。本次提交按 `localDocs/RQ.md` 要求整理，并额外融合 `movies_metadata.csv` 中的 `budget` 和 `revenue`。

当前提交文件：

| 文件 | 行数 | 说明 |
| --- | ---: | --- |
| `movies.csv` | 9727 | 电影主表，已裁剪为提交字段。 |

`movie_features.csv` 不再作为终版提交文件。

## `data/final/movies.csv`

只保留以下字段：

| 字段 | 说明 |
| --- | --- |
| `movie_id` | MovieLens 电影主键，也是项目内主键。 |
| `title_clean` | 去除年份后的 MovieLens 标题。 |
| `movie_year` | 从 MovieLens 标题解析出的年份。 |
| `genres_json` | MovieLens 类型数组 JSON。 |
| `imdb_id` | MovieLens 自带 IMDb 数字 ID。 |
| `tmdb_id` | MovieLens `links.csv` 提供的 TMDb ID。 |
| `imdb_tt_id` | 标准 `tt` 格式 IMDb ID。 |
| `rating_count` | MovieLens 评分数。 |
| `rating_mean` | MovieLens 平均评分。 |
| `rating_median` | MovieLens 评分中位数。 |
| `tag_count` | 标签数量。 |
| `top_tags_json` | 高频标签数组 JSON，最多 20 个。 |
| `overview` | TMDb 简介。 |
| `runtime_minutes` | TMDb 片长，单位为分钟。 |
| `tmdb_popularity` | TMDb 热度。 |
| `budget` | 预算，来源于 `movies_metadata.csv`，单位为美元；0 表示 metadata 未提供有效预算。 |
| `revenue` | 票房收入，来源于 `movies_metadata.csv`，单位为美元；0 表示 metadata 未提供有效票房。 |
| `original_language` | TMDb 原始语言。 |
| `poster_url` | TMDb 海报完整 URL。 |
| `backdrop_url` | TMDb 背景图完整 URL。 |

| 字段 | 说明 |
