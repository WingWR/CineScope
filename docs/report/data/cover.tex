\begin{cabstract}
  随着在线流媒体平台的普及，电影数据呈现出规模庞大、结构异构、关联复杂等特点。如何从多源异构数据中完成清洗融合，并进一步支撑检索、可视化、票房预测与个性化推荐，是数据挖掘领域具有代表性的工程问题。针对这些问题，我们设计并实现了一套面向电影数据的分析与推荐系统 CineScope。

  系统以 MovieLens、TMDb 与 IMDb 等多源数据为基础，构建了包含数据抽取、转换与加载（ETL）、探索性可视化、票房回归建模、内容推荐与协同过滤推荐、统一后端聚合以及前端交互展示的完整技术链路。在数据层，项目最终产出 9727 部电影、100811 条用户评分与 3678 条用户标签；在模型层，采用 XGBoost 与 LightGBM 加权融合完成票房预测，在验证集上取得 $R^2_{\log} \approx 0.65$；在推荐层，分别基于字符级 TF-IDF/词袋相似度与 Item/User KNN 实现内容推荐和协同过滤推荐，并通过独立微服务对外提供 HTTP 接口；在应用层，基于 React 与 FastAPI 实现电影搜索、统计可视化、RAG 问答与 Agent 推荐等功能。

  实验结果表明，CineScope 能够在统一架构下有效整合数据处理、机器学习推理与交互式服务，形成可复现、可扩展的电影数据分析工程范式。特征重要性与相关性分析进一步表明，预算与热度是票房预测的主导信号；内容推荐与协同过滤则在同系列召回与用户行为召回之间形成互补。本文还对系统局限性进行了讨论，并提出了后续在推荐评估、混合推荐与语义检索方面的改进方向。
\end{cabstract}
