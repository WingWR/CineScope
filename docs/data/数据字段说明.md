# CineScope 数据字段说明

## 数据来源与终版口径

- MovieLens `ml-latest-small`：评分、电影标题、类型、用户标签、外部 ID 映射。
- TMDb API：电影/TV 详情、简介、片长、语言、评分、投票数、热度、海报和背景图。

MovieLens 的 `movieId` 是项目内主键。MovieLens `links.csv.tmdbId` 是对接 TMDb 的主要外键；`imdbId` 仅用于 TMDb external ID 兜底匹配。

终版数据位于 `data/final/`，只保留 `tmdb_id` 非空且 `has_tmdb_detail=true` 的电影。

当前终版规模：

- 电影：9727 部
- 评分：100811 条
- 标签：3678 条
- 用户：610 名
- 类型：19 个

## 缺失值策略

- 缺失 `tmdb_id`：不进入 `data/final/`。
- 无法获取 TMDb 详情：不进入 `data/final/`。
- 缺失 TMDb 简介：`overview` 为空，由前端展示默认文案或隐藏简介区域。
- 缺失 TMDb 图片：`poster_url`、`backdrop_url` 为空，由前端展示占位图。
- 缺失 TMDb 片长：`runtime_minutes` 为空，由前端隐藏片长字段。
- 缺失标签：`top_tags_json=[]`，`tags_text` 为空。
- 缺失评分统计：评分数置 0，均分和加权分置 0。
