# CineScope 数据获取、清洗、融合与特征构造计划

## 1. 数据集选择

一期选择 GroupLens 官方 `ml-latest-small` 数据集。

选择理由：

- 数据量适合课程项目和本地开发，约 10 万条评分、约 9 千部电影、约 600 名用户，可以快速完成清洗、建模、接口联调和前端展示。
- 包含 `movies.csv`、`ratings.csv`、`tags.csv`、`links.csv`，字段覆盖电影、评分、用户标签和外部 ID 映射。
- `links.csv` 中包含 `tmdbId` 字段，可与 TMDb 数据进行匹配。
- 相比完整 MovieLens Latest，全量 TMDb 详情拉取请求量更可控；后续如需扩大规模，可以复用当前脚本流程切换到更大的 MovieLens 版本。

MovieLens 官方入口：https://grouplens.org/datasets/movielens/

## 2. 数据源

### MovieLens

- `movies.csv`：`movieId`、`title`、`genres`
- `ratings.csv`：`userId`、`movieId`、`rating`、`timestamp`
- `tags.csv`：`userId`、`movieId`、`tag`、`timestamp`
- `links.csv`：`movieId`、`imdbId`、`tmdbId`

`movieId` 是项目内主键。`tmdbId` 是优先使用的 TMDb 匹配字段；`imdbId` 仅用于 TMDb external ID 兜底匹配，不直接接入 IMDb 数据源。

### TMDb

按 MovieLens `links.csv.tmdbId` 获取详情，并标准化为项目字段。

当前拉取策略：

1. 优先请求 TMDb movie 详情。
2. 如果 movie 端点没有结果，尝试 TV 详情端点。
3. 如果 movie 和 TV 端点都没有结果，使用 MovieLens `imdbId` 转换出的 `imdb_tt_id` 调用 TMDb external ID 查询，再拉取解析出的 movie 或 TV 详情。
4. 详情请求优先使用 `zh-CN`，并用 `en-US` 结果补齐标题、简介、日期、片长、图片等字段的缺口。
5. 图片字段根据 TMDb 图片基础 URL、尺寸和 `file_path` 生成完整 URL。

凭据只从环境变量或 `data/.env` 读取，不写入代码、文档、前端或输出日志。

## 3. 目录约定

- `data/final/`：终版上传数据，供后端、算法和前端直接使用。
- `data/raw/`：MovieLens 原始文件、TMDb 原始缓存和失败记录，仅本地使用，不上传。
- `data/interim/`：清洗中间表，仅本地使用，不上传。
- `data/processed/`：融合过程产物，仅本地使用，不上传。
- `docs/data/`：面向协作成员的数据处理计划与字段说明。
- `scripts/`：可重复执行的数据处理脚本。

当前应上传 GitHub 的数据文件只放在 `data/final/`。

## 4. 清洗规则

1. 统一字段命名为 snake_case。
2. 从 MovieLens `title` 中解析 `title_clean` 和 `movie_year`。
3. 将 `genres` 中的 `|` 分隔值转换为列表；`(no genres listed)` 视为空列表。
4. 将 `timestamp` 转换为 UTC ISO 时间字段，保留原始 Unix 时间戳。
5. 将 `tmdbId` 转换为可空整数，并生成 `tmdb_id`。
6. 将 `imdbId` 转换为标准 `tt` 格式 `imdb_tt_id`，用于 TMDb external ID 兜底。
7. 标签字段去除首尾空格，生成小写归一化标签 `tag_norm`。
8. 聚合每部电影的评分数、均分、中位数、标准差、最低分、最高分。
9. 聚合每部电影的高频标签，最多保留前 20 个标签。
10. TMDb 响应不直接作为业务表结构使用，统一映射为稳定字段。
11. 终版数据只保留 `tmdb_id` 非空且 `has_tmdb_detail=true` 的电影。
12. 评分表和标签表只保留终版电影集合中的记录。

## 5. 融合策略

主键链路：

`MovieLens movieId -> links.csv tmdbId -> TMDb movie/tv detail`

兜底链路：

`MovieLens imdbId -> imdb_tt_id -> TMDb external ID -> TMDb movie/tv detail`

融合输出以 MovieLens `movie_id` 为项目内主键：

1. 合并 `movies.csv` 与 `links.csv`，得到电影基础表。
2. 以 `movie_id` 聚合评分统计，合并到电影基础表。
3. 以 `movie_id` 聚合标签统计，合并到电影基础表。
4. 用 `tmdb_id` 匹配本地 TMDb 缓存，补充外部详情。
5. 对 movie 端点失败的记录使用 TV 端点兜底。
6. 对 movie 和 TV 端点都失败的记录使用 `imdb_tt_id` 进行 TMDb external ID 兜底。
7. 生成展示字段、搜索字段、推荐特征字段。
8. 过滤掉缺失 `tmdb_id` 或无法获取 TMDb 详情的电影，生成 `data/final/` 终版文件。

## 6. 特征构造

面向电影检索：

- `display_title`
- `display_year`
- `genres_json`
- `tmdb_genres_json`
- `top_tags_json`
- `search_text`
- `poster_url`
- `backdrop_url`
- `overview`

面向推荐算法：

- 评分统计：`rating_count`、`rating_mean`、`rating_median`、`rating_std`
- 热门度特征：`rating_count`、`tmdb_popularity`、`tmdb_vote_count`
- 内容特征：`feature_text`、类型 one-hot、标签文本、简介文本、语言、年份
- 排序基线：MovieLens 加权评分 `weighted_rating`

面向前端分析：

- 数据集概览：电影数、用户数、评分数、标签数、TMDb 详情覆盖数
- 类型分布
- 评分分布
- 热门电影与高分电影候选
- TMDb 海报、背景图、简介和评分展示

## 8. 执行策略

默认执行 MovieLens 下载、解压、清洗、融合本地缓存和特征构造。

TMDb 拉取必须显式开启：

- 小样本验证：`python scripts/prepare_movie_data.py --fetch-tmdb --tmdb-limit 20`
- 全量拉取：`python scripts/prepare_movie_data.py --fetch-tmdb --allow-full-tmdb`

脚本会缓存成功结果，后续重复执行会优先使用本地缓存并补拉缺失记录。
