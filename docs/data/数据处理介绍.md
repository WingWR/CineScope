# CineScope 数据处理介绍

本目录说明 `data/final/` 下的提交版数据。数据来源为 MovieLens `ml-latest-small`、TMDb 详情数据和 `movies_metadata.csv`。

## 数据范围

- MovieLens 原始电影数：9742
- 缺失 `tmdb_id` 并剔除：8 部
- 有 `tmdb_id` 但无法获取 TMDb 详情并剔除：7 部
- 终版电影数：9727
- 终版评分数：100811
- 终版标签数：3678
- MovieLens 类型数：19
- 匹配到预算/票房 metadata：9386 部
- `budget > 0`：5844 部
- `revenue > 0`：6235 部

终版电影均满足：

- `tmdb_id` 非空
- 已成功匹配 TMDb 详情

## 使用建议

后端可优先使用：

- `movies.csv`：电影基础信息、评分统计、TMDb 简介、图片 URL、预算和票房
- `ratings.csv`：用户评分行为
- `tags.csv`：规范化标签
- `genre_stats.csv`：类型分布

前端展示可优先使用：

- 标题：`title_clean`
- 年份：`movie_year`
- 类型：`genres_json`
- 简介：`overview`
- 评分：`rating_mean`
- 热度：`tmdb_popularity`
- 预算：`budget`
- 票房：`revenue`
- 海报：`poster_url`
- 背景图：`backdrop_url`

算法侧可优先使用：

- 协同过滤：`ratings.csv`
- 内容特征：`movies.csv` 中的 `genres_json`、`top_tags_json`、`overview`、`original_language`
- 热度与排序：`rating_count`、`rating_mean`、`rating_median`、`tmdb_popularity`
- 财务分析：`budget`、`revenue`

## 缺失值处理

- 缺失 `tmdb_id` 的电影不进入终版。
- 无法获取 TMDb 详情的电影不进入终版。
- `overview`、`runtime_minutes`、`poster_url`、`backdrop_url` 可能为空，原因是 TMDb 对少量条目未提供对应字段。
- `budget`、`revenue` 使用 0 表示 `movies_metadata.csv` 未提供有效数值，不能直接解释为真实预算或票房为 0。
- 标签缺失时，`top_tags_json` 为 `[]`。
